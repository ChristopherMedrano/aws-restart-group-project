# Wireframe exports

No fake image placeholders are committed. When approved visual wireframes are
added, use these stable filenames:

- `application-shell-desktop.png`
- `application-shell-mobile.png`
- `assigned-tasks-states.png`
- `created-tasks-states.png`
- `create-task-states.png`
- `notification-history-states.png`
- `profile-states.png`
- `callback-and-system-states.png`

The reference layouts are in [`screens.md`](screens.md), and the required state
coverage is in [`screen-state-matrix.md`](screen-state-matrix.md). Use both
documents to create the actual wireframes. Each export must show the applicable
desktop and phone-sized states, including focus, loading, success, and error
behavior.
